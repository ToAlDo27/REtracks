# ReTracks — музыка для Owlbear Rodeo

Автор ReTracks — [ToAlDo27](https://github.com/ToAlDo27).

[История изменений](CHANGELOG.md) также открывается по кнопке версии в панели расширения и на странице установки. Адрес репозитория и установочная ссылка сохранены.

Доработанная версия [hypergig/obr-tracks](https://github.com/hypergig/obr-tracks). Исходный автор — Jordan Cohen, лицензия AGPL-3.0.

**Установочная ссылка:** [манифест ReTracks](https://toaldo27.github.io/REtracks/manifest.json). Добавьте этот адрес в Owlbear Rodeo → Extras → Extensions → Add custom extension.

## Что добавлено

- Кнопка **Add music**: аудиоссылки и YouTube, по одному или списком.
- Массовое добавление: вкладка **Multiple tracks**, одна ссылка на строку. Можно указать `Название | URL`.
- **Edit**: изменение названия, URL, тегов, начала и конца фрагмента в секундах. Фрагмент зацикливается; таймкод из ссылки YouTube подставляется автоматически.
- Отмена устаревших запросов при быстром переключении, ограниченный кеш длительности, таймауты и очистка плееров. Поздняя загрузка прежнего трека не должна включать его заново.
- Прямое аудио сверяется с общей позицией комнаты после задержек загрузки и возврата из фоновой вкладки. Позднее подключение, пауза, продолжение, перемотка и смена трека используют общее состояние воспроизведения.
- Видимый YouTube-плеер, перемотка и понятные ошибки воспроизведения. Если браузер блокирует запуск, есть кнопка **Play YouTube on this device**.
- **Share tab audio**: трансляция звука из отдельной вкладки браузера участникам комнаты.
- Исправлены проверка и объединение библиотеки, дубли, редактирование URL и импорт/экспорт CSV. Старый CSV с `title,url,tags` поддерживается; для фрагментов добавляются `start,end`.
- Удалено подключение аналитики исходного автора из самостоятельной сборки.

## Установка через GitHub Pages

1. Загрузите исходные файлы в свой публичный репозиторий `REtracks`, включая папку `.github/workflows/`, в ветку `main`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Если первая попытка запуска была до включения Pages, во вкладке **Actions** повторно запустите **Publish ReTracks to GitHub Pages**.
3. Дождитесь публикации и откройте [сайт ReTracks](https://toaldo27.github.io/REtracks/). На странице есть кнопка копирования установочной ссылки.
4. В Owlbear Rodeo откройте **Extras → Extensions → Add custom extension**, вставьте `https://toaldo27.github.io/REtracks/manifest.json` и включите ReTracks в комнате. Для собственного форка замените `toaldo27` на логин его владельца.
5. Откройте ReTracks, нажмите значок выключенного звука, затем **Add music**. Участникам тоже нужно разрешить звук в своём браузере.

Workflow автоматически проверяет, собирает и публикует расширение при обновлении ветки `main`. Путь GitHub Pages определяется автоматически, включая переименование репозитория и собственный домен. Установочная ссылка должна вести на опубликованный `manifest.json`: ссылка на репозиторий GitHub или исходный файл для установки не подходит.

Сборка не публикует изменения на сайте автора. Старый адрес `obr-tracks.web.app/manifest.json` продолжает открывать исходную версию.

## Другой HTTPS-хостинг

Разместите содержимое `dist/` в корне HTTPS-сайта. Для подпапки задайте `VITE_BASE_PATH=/имя-папки/` при выполнении `npm run package`: сборщик изменит пути ресурсов и манифеста. Файлы `index.html`, `broadcast.html`, `manifest.json` и папка `assets/` должны оставаться рядом. Хостинг должен отдавать отдельную страницу `broadcast.html`, не подменяя её основной страницей. Запуск через `file://` для Owlbear не подходит.

Библиотека хранится в браузере и привязана к адресу сайта. Перед переходом экспортируйте CSV из старой версии и импортируйте его в новую. Само аудио нужно заранее разместить по публичной ссылке: облачное хранилище файлов в расширение не входит.

## Как транслировать вкладку

1. Ведущий открывает музыку в отдельной вкладке, затем в ReTracks нажимает **Share tab audio**.
2. В появившемся окне нажимает **Choose tab and start**, выбирает вкладку с музыкой и включает **Поделиться аудио вкладки / Share tab audio**.
3. Участники нажимают **Listen to tab audio**: кнопка включает звук и устанавливает громкость 30%, если она была на нуле. При блокировке автозапуска браузером нужно нажать **Enable stream audio**. Громкость и ручное отключение звука продолжают работать.
4. Песни переключаются в исходной вкладке. Окно трансляции и комнату Owlbear нужно оставить открытыми. **Stop broadcast** завершает трансляцию; **Disconnect** отключает одного слушателя.

Для захвата используйте настольный Chrome или Edge. Если выбран экран или окно без звуковой дорожки, интерфейс попросит выбрать вкладку со звуком. По соединению передаётся только аудио. Громкость и отключение звука у каждого слушателя свои; звук библиотеки приглушается на время трансляции или прослушивания.

Используется прямое WebRTC-соединение и STUN. **TURN-сервер в сборку не входит**: в некоторых сетях соединение может не установиться. Нагрузка на исходящий интернет ведущего растёт с числом слушателей. Разрешите всплывающее окно; заголовки хостинга не должны разрывать связь `window.opener` с расширением.

## YouTube

YouTube запускается через официальный видимый плеер на каждом устройстве. Доступность ролика, реклама, региональные ограничения, запрет встраивания и блокировка автозапуска могут влиять на синхронность. Название, теги и границы фрагмента меняются в ReTracks; само видео на YouTube не редактируется и не скачивается.

## Сборка из исходников

Перед каждым опубликованным обновлением выполните `npm run release -- patch "Описание изменения"` (или `minor` / `major`). Команда одновременно повышает версию в package.json, package-lock.json и манифесте, дополняет историю в интерфейсе и CHANGELOG.md. `npm run check:release` проверяет их согласованность, а GitHub Actions отклоняет публикацию изменений приложения без повышения версии. Нумерация ReTracks начинается с 1.0.0; ключи библиотеки и синхронизации не меняются.

Требуются Node.js 20+ и npm:

```sh
npm ci
npm test
npm run lint
npm run test:browser
npm run package
```

Последняя команда создаёт `dist/` со сборкой, лицензией и файлом `SOURCE.txt`, в котором указана ссылка на соответствующую версию исходников в репозитории. Для браузерных тестов нужен Chrome/Chromium; расположение можно указать через `PLAYWRIGHT_CHROME_PATH`. Тесты используют подменённый транспорт Owlbear и не требуют аккаунта.

Отдельная ссылка **Source code** на странице установки и в меню расширения открывает [репозиторий REtracks](https://github.com/ToAlDo27/REtracks). Архив исходников сайт не создаёт и не предлагает скачать. При публикации сохраняйте файлы `LICENSE.txt` и `SOURCE.txt`. Для Firebase предварительно выберите свой проект — конфигурация проекта автора удалена.

Автоматически проверяются библиотека, отмена загрузок, плееры, фрагменты и обмен сигналами. Браузерные проверки используют реальные аудио/WebRTC API с подменённым Owlbear. Проверка в живой комнате с несколькими участниками и проверка внешних YouTube-роликов выполняются после размещения на HTTPS-хостинге.
